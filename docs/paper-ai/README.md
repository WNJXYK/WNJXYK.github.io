# Per-paper AI image records

For each newly generated publication infographic, add one `<publication-id>.md` file here using the template in [../publication-ai-images.md](../publication-ai-images.md#9-每篇论文的生成记录模板).

Record the sources read, the verified content outline, the final prompt, and the visual checks. Do not store drafts or generated images in this directory; final images belong in `public/images/paper-ai/`.
